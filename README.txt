WELLNESS SCHOOL PROJECT — MOBILE & TABLET READY

1. Connect the laptop and mobile/tablet to the SAME Wi-Fi.
2. On the laptop, open a terminal in this folder and run:

   python server.py

3. The terminal displays:
   - Laptop URL: http://localhost:8000
   - Mobile/tablet URL: http://YOUR-LAPTOP-IP:8000

4. Open the mobile/tablet URL in Chrome, Safari, Edge, or another modern browser.

CAMERA NOTE
Mobile browsers usually require HTTPS before allowing live camera access when opening a site through a Wi-Fi/LAN address. Therefore:
- On the laptop using localhost: camera should work.
- On a phone/tablet using the LAN HTTP address: use Upload Photo if the browser blocks live camera.
- For full mobile live-camera support, deploy this folder to any HTTPS web host.

The layout is responsive for phones, tablets, iPads, and laptops and supports touch controls.
